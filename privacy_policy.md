# Privacy Policy for Devinorium

**Effective date:** 2026-09-07

## Overview

Devinorium is a self-hosted web UI for AI coding agents. This means you run the application on your own server or hardware, and the data you create is stored on that instance. The Devinorium project does not operate a central service, and we do not receive, host, or process your data unless you choose to use an instance managed by someone else.

This policy describes what data Devinorium handles and how it is used. If you are using an instance run by another person or organization, that operator is responsible for their own privacy practices.

## Data Devinorium processes

When you use Devinorium, the application processes the following categories of information, all of which are stored locally on the server you control:

- **Account information**: usernames, hashed passwords, optional two-factor authentication secrets, roles, and session cookies.
- **Provider configuration**: the command and connection settings for the AI provider you choose, such as Devin CLI or OpenCode.
- **Git host credentials and tokens**: if you connect GitLab or GitHub, the access tokens and related account information you provide are stored on the server.
- **Files and user content**: project files, uploaded attachments, messages, prompts, code, and any other content you upload or generate while using the agent.
- **Agent and provider interactions**: the content you send to and receive from your configured AI provider or Git hosting service.
- **Server logs and diagnostics**: log output and runtime diagnostics generated by the application are kept on the server and are not transmitted to the project maintainers.

## How we use data

Devinorium uses this data only to provide the functionality of the application, such as:

- Authenticating users and maintaining sessions.
- Storing and displaying your projects, threads, and files.
- Running the configured AI provider to process your requests.
- Interacting with connected Git hosts to fetch, create, or update repositories and merge requests.

We do not use your data for advertising, profiling, or any purpose beyond operating the application.

## Data sharing

The Devinorium project does not collect or sell your data. Data is shared only with the services you explicitly configure, such as:

- The AI provider you select (for example, Devin CLI or OpenCode).
- The Git host you connect to (for example, GitLab or GitHub).

The operator of your instance is responsible for the server and any additional services it is connected to.

## Security

Because Devinorium is self-hosted, you or your instance operator are responsible for securing the server. We strongly recommend enabling HTTPS, using strong passwords, enabling two-factor authentication, and keeping the application and operating system up to date.

## Data retention and deletion

There is no central database controlled by the Devinorium project. Data is retained for as long as your server keeps it. You or your instance operator can delete data at any time by removing files, database records, or the entire server deployment.

## Children's privacy

Devinorium is not directed to children under the age of 13. If you are running an instance for users under 13, you are responsible for meeting the privacy requirements that apply to them.

## Changes to this policy

We may update this privacy policy as the project changes. The latest version will always be available at the Devinorium repository.
